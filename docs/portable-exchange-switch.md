# 便携式交换机（Portable Exchange Switch）

手持物品，右键打开一个简化版的交换机界面：没有侧面配置、升级、遗忘槽、物品槽与能量槽，所有交换**即时完成**（无需电力、无需等待）。SV 与知识与方块交换机**共享同一份玩家数据**（服务端权威）。

## 合成

```
传送核心  钋球      传送核心
反物质球  交换机    反物质球
传送核心  钋球      传送核心
```

物料：传送核心（`mekanism:teleportation_core`）、钋球（`mekanism:pellet_polonium`）、反物质球（`mekanism:pellet_antimatter`）、交换机（`meks:exchange_switch`）。

## 界面

- 8 列 × 5 行知识库（与玩家物品栏同尺寸、左对齐），支持搜索与滚动，悬停显示名称与 SV。
- 库与物品栏之间的间隔居中显示当前 SV。
- 不渲染“物品栏”标签（与方块交换机界面一致）。

## 操作

| 操作 | 效果 |
|---|---|
| 左键点击背包物品 | 上传 1 个，即时获得 SV 并解锁知识 |
| Shift+左键点击背包物品 | 上传整组 |
| 左键点击库条目 | 下载 1 个（扣除 SV，生成真实物品进背包空位） |
| Shift+左键点击库条目 | 下载整组（不超过物品最大堆叠） |
| Shift+右键点击库条目 | 下载半组（向上取整，不遗忘） |
| **右键点击库条目** | **下载 1 个，成功后遗忘该知识**（防误操作） |

### 遗忘说明

右键遗忘 = 先成功下载 1 个（扣 SV、物品进背包），**下载成功后**才删除知识。因此以下情况**不会**误删知识：

- SV 不足以支付 1 个物品时，下载失败，知识保留。
- 背包没有空位时，下载失败，知识保留。

遗忘成功会有提示（如“已遗忘 钻石”）。

## 限制

- 禁止上传 SV 值为 0 的物品（提示“该物品没有 SV 值”）。
- 禁止上传便携式交换机自身。
- 下载目标必须已解锁知识（服务端校验）。
