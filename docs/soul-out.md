# 灵魂出窍（Soul Out of Body）

纯客户端功能：穿戴 MekaSuit 头盔时，按下默认按键 F4（可在“控制”中改键），灵魂离开身体，相机可以自由穿墙飞行；身体留在原地。再次按下 F4 回到身体。

## 规则

- 必须穿戴 MekaSuit 头盔（头盔槽位）才能开启。
- 出窍期间禁止攻击、挖掘、拾取、使用物品以及与方块/实体交互。
- 出窍期间按 F5 无效，视角由功能接管。
- 非创造模式按秒指数增长消耗头盔能量：起始 500 J/t，每 45 秒翻倍。
- 能量不足、脱掉头盔、受伤（生存/冒险模式）、重生、切换维度、断线都会自动回体。
- 创造模式不消耗能量，也不会因能量耗尽回体。

## 配置

`config/Mekanism/meks-client.toml` 中 `soulOut` 分组：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `baseCostPerTick` | `500` | 起始能耗（J/t），仅非创造模式生效 |
| `costDoublingSeconds` | `45` | 能耗翻倍周期（秒），`0` 表示恒定消耗 |
| `horizontalSpeed` | `1.0` | 灵魂水平移动速度 |
| `verticalSpeed` | `1.0` | 灵魂垂直移动速度 |
| `freezeBody` | `true` | 出窍时冻结身体位置（客户端） |
| `showBody` | `true` | 出窍时显示身体 |
| `disableOnDamage` | `true` | 受伤自动回体 |

## 说明

- 实现参考 Freecam（hashalite，MIT）的分离相机机制，仅保留灵魂出窍所需部分。
- 灵魂实体是纯客户端对象，不向服务器发送任何数据包；其他玩家看不到灵魂。
- `freezeBody` 在部分多人服务器上可能被服务端的位置校正拉回，若出现回弹可将其关闭。
